================================================================================
ART GALLERY SHOWCASE - DATA FLOW DIAGRAMS (DFD)
================================================================================
This file contains Mermaid diagram code for DFD Level 0, Level 1, and Level 1.1
through 1.4 (by module/role per project_spec.txt). Copy each code block into
Mermaid-supported tools (e.g. Mermaid Live Editor, GitHub, Notion, Cursor).

DFD Notation in Mermaid:
  - External entities: ( ) rounded rectangles
  - Processes: ([ ]) stadium shape
  - Data stores: [[ ]] cylinder/subroutine shape
  - Data flows: arrows with labels

================================================================================
DFD LEVEL 0 - CONTEXT DIAGRAM (ENTIRE PROJECT)
================================================================================
Single process representing the whole Art Gallery Showcase system; external
entities are Artist, Visitor, and Admin; main flows and central data store.

--- Mermaid code (Level 0) ---

flowchart LR
  subgraph External Entities
    A[(Artist)]
    V[(Visitor/Customer)]
    AD[(Admin)]
  end

  S([Art Gallery Showcase System])

  subgraph Data Store
    DB[(Database)]
  end

  A -->|Register/Login, Upload/Edit Artworks, View Sales| S
  S -->|Auth Response, Artwork Status, Sales Data| A

  V -->|Browse, Register/Login, Place Orders, View History, Place Bids| S
  S -->|Artworks, Order Confirmation, Auction Updates| V

  AD -->|Login, Manage Users/Artworks/Orders, Approve Artists, Categories, Reports| S
  S -->|Dashboard Data, Reports, User/Order Lists| AD

  S <-->|Read/Write Users, Artworks, Orders, Auctions, Bids, Categories| DB

--- End Level 0 ---


================================================================================
DFD LEVEL 1 - SYSTEM DECOMPOSITION (ENTIRE PROJECT)
================================================================================
Level 1 breaks the system into major processes: Authentication, Artist Module,
Visitor/Customer Module, Admin Module, and Auction Module, with shared
data stores.

--- Mermaid code (Level 1) ---

flowchart TB
  subgraph External
    A[(Artist)]
    V[(Visitor/Customer)]
    AD[(Admin)]
  end

  subgraph Processes
    P1([1.0 Authentication])
    P2([2.0 Artist Module])
    P3([3.0 Visitor/Customer Module])
    P4([4.0 Admin Module])
    P5([5.0 Auction Module])
  end

  subgraph Data Stores
    D1[[Users]]
    D2[[Artworks]]
    D3[[Orders]]
    D4[[Auctions]]
    D5[[Bids]]
    D6[[Categories]]
    D7[[Transactions]]
  end

  A -->|Register/Login| P1
  P1 -->|Token, User| A
  P1 <--> D1

  A -->|Upload/Edit/Delete Artwork, View Sales| P2
  P2 -->|Artwork Status, Sales Data| A
  P2 <--> D2
  P2 --> D7
  P2 <--> D1

  V -->|Register/Login| P1
  V -->|Browse, Filter, Place Order, View Orders| P3
  P3 -->|Artworks, Order Status| V
  P3 <--> D2
  P3 <--> D3
  P3 <--> D1

  AD -->|Login| P1
  AD -->|Manage Users, Artworks, Orders, Categories, Reports| P4
  P4 -->|Dashboard, Reports, Lists| AD
  P4 <--> D1
  P4 <--> D2
  P4 <--> D3
  P4 <--> D6
  P4 --> D7

  A -->|Create Auction, View Bids, Finalize| P5
  V -->|Place Bid, View Auctions| P5
  P5 -->|Auction/Bid Status| A
  P5 -->|Auction Results, Outbid Notifications| V
  P5 <--> D4
  P5 <--> D5
  P5 <--> D2
  P5 --> D7

--- End Level 1 ---

DFD LEVEL 1.4 - AUCTION MODULE

Allow multiple users to place bids, View all bids, Finalize auction and
select highest bidder, Mark artwork as sold after completion.

--- Mermaid code (Level 1.4) ---

  A[(Artist)]
  V[(Visitor/Customer)]

  subgraph Auction Module 1.4
    P1([1.4.1 Create Auction])
    P2([1.4.2 Place Bid])

    P4([1.4.4 Finalize Auction])
    P5([1.4.5 Mark Artwork Sold])
  end

  D2[[Artworks]]
  D4[[Auctions]]
  D5[[Bids]]
  D1[[Users]]
  D7[[Transactions]]

  A -->|Artwork, Base Price, Duration| P1
  P1 -->|Auction Created| A

USAGE NOTES
================================================================================
- To render: paste a single "--- Mermaid code ... ---" block into
  https://mermaid.live or any Mermaid-capable viewer.
- Level 0 and Level 1 use the full system; Level 1.1–1.4 zoom into each
  role/module from project_spec.txt (Artist, Visitor/Customer, Admin, Auction).
- Data stores align with server models: User, Artwork, Order, Auction, Bid,
  Category, Transaction, Setting (Setting omitted in DFD for brevity; can be
  included under Admin "Manage Categories & Content" if needed).
